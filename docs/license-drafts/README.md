# ร่างใบอนุญาตของ THdocs (ยังไม่มีผลใช้งาน)

โฟลเดอร์นี้มี**ร่าง**ให้ตัดสินใจ — ยังไม่ได้ใช้เป็น `LICENSE` ของ repo จนกว่าเจ้าของจะเลือกและ (ควร) ให้ทนายตรวจ
ผู้เขียนร่างไม่ใช่ที่ปรึกษากฎหมาย

| ไฟล์ | คืออะไร |
|---|---|
| `AGPL-3.0.txt` | ข้อความทางการของ GNU AGPL v3 ดาวน์โหลดจาก gnu.org (34,523 ไบต์, sha256 `0d96a4ff…abcb0`) |
| `MIT.txt` | MIT แบบมาตรฐาน มีช่องชื่อเจ้าของลิขสิทธิ์ |
| `CLA.draft.md` | ฉบับร่างข้อตกลงผู้ร่วมพัฒนา — **ยังไม่ใช้** (ใช้เมื่อจะรับโค้ดภายนอกและมีทนายตรวจแล้ว) |
| `COMMERCIAL-LICENSE.draft.md` | โครงใบอนุญาตเชิงพาณิชย์ใช้คู่กับ AGPL (dual licensing) ต้องให้ทนายร่างจริง |

## เลือกแบบไหน

| | MIT | AGPL-3.0 | AGPL + ใบอนุญาตเชิงพาณิชย์ (dual) |
|---|---|---|---|
| ใครนำไปใช้/ขาย/ดัดแปลงได้ | ทุกคน ไม่มีเงื่อนไขเปิดโค้ด | ทุกคน แต่ต้องเปิดโค้ดที่แก้ **รวมถึงเมื่อให้บริการผ่านเว็บ** | AGPL สำหรับทั่วไป / จ่ายเงินเพื่อไม่ต้องเปิดโค้ด |
| กันคู่แข่งทำ SaaS จากโค้ดเรา | ไม่ | ช่วยได้ (ต้องเปิดโค้ดส่วนที่แก้) | ช่วยได้ และมีทางขายสิทธิ์ให้ผู้ที่ไม่อยากเปิดโค้ด |
| องค์กร/ราชการยอมใช้ไหม | ง่ายที่สุด | บางแห่งห้ามใช้ AGPL ตามนโยบาย | แก้ได้ด้วยการซื้อใบอนุญาตเชิงพาณิชย์ |
| ต้องมีอะไรเพิ่ม | ไม่ | ไม่ | **ต้องถือลิขสิทธิ์ทั้งหมด** → ผู้ร่วมพัฒนาต้องเซ็น CLA/โอนสิทธิ์ ก่อนรับโค้ดจากภายนอก |
| เหมาะกับโมเดล | A (เปิดฟรีเพื่อขยายฐาน) | A/D | **D ผสม** และ C (ขายติดตั้งเอง) |

หมายเหตุ: ถ้าไม่เคยรับโค้ดจากคนอื่นเลย คุณถือลิขสิทธิ์ทั้งหมดอยู่แล้ว เลือก dual ได้ทันที แต่ถ้ารับ pull request ภายนอกโดยไม่มี CLA จะเปลี่ยนเป็น dual ภายหลังยาก
ถ้าเลือก MIT แล้วเปิดสาธารณะ จะ**เรียกคืนไม่ได้** สำหรับเวอร์ชันที่เผยแพร่ไปแล้ว

## ถ้าเลือกแล้ว ทำตามนี้
1. คัดลอกไฟล์ที่เลือกเป็น `LICENSE` ที่รากของ repo (AGPL: ใช้ `AGPL-3.0.txt` ทั้งไฟล์) และกรอกชื่อเจ้าของลิขสิทธิ์
2. แก้ `NOTICE` ให้ระบุเจ้าของลิขสิทธิ์จริงและใบอนุญาตที่เลือก พร้อมประกาศ third-party (ไลบรารี MIT/Apache และ JSZip ที่เลือกใช้ในเงื่อนไข MIT)
3. ใส่ `"license"` ใน `package.json` (`AGPL-3.0-or-later` / `MIT` / `AGPL-3.0-or-later OR LicenseRef-THdocs-Commercial`)
4. ถ้าเลือก AGPL: ใส่ลิงก์ "ซอร์สโค้ด" ในหน้าเว็บ (AGPL มาตรา 13 กำหนดให้ผู้ใช้ที่ใช้งานผ่านเครือข่ายเข้าถึงซอร์สโค้ดเวอร์ชันที่รันอยู่ได้) — ยังไม่ได้ทำ
5. ถ้าเลือก dual: เพิ่ม `CONTRIBUTING.md` และ CLA, ให้ทนายร่าง `COMMERCIAL-LICENSE`
6. ตราครุฑ ตราหน่วยงาน ฟอนต์ TH Sarabun **ไม่อยู่ใต้ใบอนุญาตของซอฟต์แวร์** (ระบุไว้ใน NOTICE แล้ว) ให้คงไว้

- เจ้าของลิขสิทธิ์ (บุคคลหรือนิติบุคคล) และชื่อที่ใช้แสดง
